# Mixtape

A music player with a city-pop look: favorite songs, each with its own page and cover, ready to share with a link. Part of [alexitp1125.com](https://alexitp1125.com).

- Audio always plays through the official YouTube player.
- Covers are original designs.
- Installable as an app on phones and computers.

**Status:** in development.

## Stack

.NET 10 · Blazor Web App (static SSR + WebAssembly) · Docker

## Run locally

```
dotnet run --project Mixtape
```

Then open http://localhost:5080.
